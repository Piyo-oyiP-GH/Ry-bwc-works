# デモ動画を作る仕組み

ステータス: **作ることは決定**。中身は検討中

## 目的

- 動画を作ったことがなくても、11/7 の1日で質の高いデモ動画を仕上げられるようにする
- 機能ができるたびに動画を少しずつ育て、最終日に一から作らなくて済むようにする

## 決定事項

- 仕組みは必ず作る
- **まず別リポジトリで簡単な仕組みを試す**（本リポジトリには、動くことを確かめてから持ち込む）
- 機能ができるたびに**絵コンテに1行足して、画面録画を撮る**。これは毎回やる

## 全体の流れ：素材撮影と動画化を分ける

- **素材撮影**：機能ができるたびに録画する（オリジナル）
- **動画化**：他の参加者・メンターの方式を踏襲する

動画化の手順：

1. **絵コンテ表をアーティファクトで作る。** シーンごとに「秒数・見せる画面・テロップ・ナレーション」を1行ずつ並べる。構成の修正は、動画にする前にここで済ませる
2. **絵コンテをもとに動画を作ってもらう。** 最初は仕上がりにこだわらず、短いプレビューで流れを確認する
3. **修正は時間やシーン番号で伝える。** 例：「0:32の見出しを短く」「シーン3を2秒詰めて」。フィードバックは絵コンテ（アーティファクト）に対して行う

## 構想：素材を先に撮り、動画化の方法は後から差し替える

撮った素材を「素材」と「動画化」に分けておき、動画化の方法を複数に分岐できるようにする。

```
素材（録画・絵コンテ・メタデータ）
        │
        ▼
  ベースの動画化（最低限：録画をつなげてテロップを乗せる）
        │
        ├─ 追加の動画化 A（例：Remotion でアニメーション付き）
        └─ 追加の動画化 B（例：ナレーション音声つき）
```

### 素材の撮り方（案）

- 録画には**テロップや装飾を焼き込まない**（あとで方式を変えられるように）
- 音声は別トラック、または無音で撮る
- 機能ごとに短いクリップに分ける。ファイル名に日付と機能名を入れる
- 各クリップに、絵コンテの行（シーン番号）を対応させる

### 絵コンテの形式（メンター推奨）

シーンごとに1行で並べる。

| シーン | 秒数 | 見せる画面 | テロップ | ナレーション |
|---|---|---|---|---|
| 1 | 0–10 | | | |

- 構成の修正は、動画にする前に絵コンテの段階で済ませる。こうすると大きなズレが出ない
- 最初は仕上がりにこだわらず、短いプレビューで流れを確認する
- 修正は秒数やシーン番号で伝える

### 他の参加者の例

絵コンテをアーティファクトで作り、それをもとに動画を生成する。フィードバックはアーティファクトに対して行い、修正してもらう。
