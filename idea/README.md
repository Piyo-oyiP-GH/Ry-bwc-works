# 作品のアイデア

> 版：仮 v0（2026-11-05）。すべて仮決定。経緯は [design-flow.md](../design-flow.md) と [decisions.md](../decisions.md)。
> 元の検討記録は PC の `試作/1104_アイデアの土台固め/`（PCのみ。家族の私的な事情を含むので公開しない）。

## 一言で

捨てる前に現場を撮っておけば、その場にいない家族も、あとから中身を見て「待った」をかけられる。

## 出発点（体験）

親族の家の家財整理で、父は中身を見ずに、すべて業者に任せて処分するつもりだった。自分が引き渡しの前に待ったをかけて仕分けに行くと、祖父の古い写真や、父が作った歌などが見つかった。**自分がいなければ、現場にいたのは業者だけだった。**

## 誰の・どんな困りごとか（問題文・仮）

本人に聞けず、時間と衛生の制約もある中で、中身を見る前に「全部捨てる」ことになる場合がある。親族は、判断の材料が足りないまま決めてしまい、家族の歴史を示す物が気づかれずに失われ、あとで後悔する。

- 主体は家族（自分）。本人への効果は未検証なので言わない
- 「場合がある」の根拠は、自分の1件と友人の1件。頻度は不明

## 売り（仮）

**自分がした「待った」の役割を、その場にいない家族にも渡す。**
その場で中身を見る人がいない理由は、遠い・忙しい・体力がない・疎遠など、ふつうにある（下の根拠）。

## どう解決するか（解決の文・仮）

1. **撮る**：捨てる前に、現場を素早く撮る。まず写真から（動画は後で）
2. **索引にする**：AI が写真から、どこに何があったか、読める文字や名前、物どうしのつながりを拾う
3. **見直して決める**：家族が、離れた所や清潔な場所で、あとから見直して、残すか捨てるかを決める

AI は大切かどうかを判断しない。「捨ててよい」とも言わない。

## 撮る人（仮）

- 行ける家族がいるなら、その人が短時間だけ行って撮る（撮るのは、見て決めるより短く、判断も要らない）
- 行ける家族がいないなら、業者が引き渡しの前に撮る
- デモは自分が撮る。業者の問題は言わない（「頼む側が見られるようにする」まで）

## 根拠（公的な調査を中心に）

- 遺品整理業者の 44/52 社が「依頼者は別居が多い」。依頼の理由は「遠方」が最多で、「多忙」「体力的に困難」「疎遠」も多い（総務省行政評価局、2020）
- 原則として立ち会い不要とする遺品整理業者は 14/69 社（同上）
- 同居の介護で、介護する人もされる人も65歳以上が 61.9%（厚生労働省「2025年 国民生活基礎調査」）
- 「残してほしいと頼んだ物を無断で処分された」という相談がある（国民生活センター）
- 処分前に最終確認の機会がほしい 27.0%、ただし「特に必要ない」も 45.0%（遺品整理業者の調査。企業調査）
- 業者に頼んで何らかのトラブルがあった 36.2%（企業調査。「捨てられた」という項目はない）

言い切れないこと：捨てられた物の割合の数字はない。データの多くは亡くなった後の話。

## MVP（範囲は未決定）

- [ ] 写真を入れると、読める文字・名前・物の一覧（索引）が出る
- [ ] 家族が、離れた所から一覧を見て、残す／捨てる／保留を決められる

## 余裕があれば

- 短い動画からコマを取り出して読む
- 業者が撮る形
- 物どうし・物と人物のつながりの記録（段階2・3）

## 未確定・要検討

- 動かす場所（スマホのブラウザか、PC か）
- 写真からどこまで読めるか（実物で試す。家族の写真を AI に送るかは先に決める）
- なぜ AI が要るか（「写真を撮って LINE で送れば済むのでは？」への答え）
- 業者が撮ることに協力するか（ヒアリング未実施）
- 禁止例（汎用の画像解析ツール）に当たらないか、メンターに確認（未実施）
