# 作品の仕様 v1（2026-11-06）

> 変更点：動画と現場の音声をやめ、静止画・モノカード・人物カード・待ったに絞った。

## 一言

その場にいない家族も、捨てる前に「待った」をかけられるようにする。

## 使う人

| 人 | すること |
|---|---|
| 現場の親族 | 自分で決められない物を、静止画で1枚ずつ撮る |
| Claude | モノカードと人物カードを作る |
| 離れた親族 | 一覧を見て、物ごとに「待った」を押す。1人でも押せば残す |

## 作る機能

| 機能 | 中身 |
|---|---|
| 写真を撮る | スマホの標準カメラを呼び出す。送る前に端末の中で縮小する |
| モノカード | 物の種類、見えた根拠、読めた文字 |
| 人物カード | 読めた名前、持ち主の傾向の仮説（強さと根拠の写真番号つき）。写真が増えるほど更新する |
| 一覧の共有と待った | 撮った物が1つの一覧にたまる。初回に名前だけ入れて登録する。物ごとに待ったとひとことを残せる。1人でも押せば残す |
| 見本を見る | 保存済みの架空の記録。AI を呼ばない |

## Claude の決まり

- 写真に写っている物だけを根拠にする。写っていない中身を推し量らない
- 「大切です」「捨ててよい」とは言わない。根拠と仮説だけを示す。決めるのは家族
- 人物の仮説は断定しない。強さと根拠を必ず付ける
- 顔で人物を見分けない。同じ人かの照合もしない。つなぎは文字で行う
- 読めない文字を推測で補わない

## 試作で分かったこと（実装で守る）

- 文字を読む処理は、分類と分ける。一緒にすると読める量が大きく減る
- 回転は写真の向き情報に従うだけにする。手で回さない
- 同じ物をまとめる処理はしない
- 人物カードは全部の写真を送り直さない。カードの文章と新しい写真で更新する
- モデルは Opus 5.5 を使う。Haiku 5.5 との速度の差は小さかった
- 解析の失敗で写真を一覧から消さない。「未解析」で残す

## 作らないもの

動画（発展の補助）、自動撮影、現場の音声、場所の記録、部屋の 3D、業者が撮る形、ログイン（本番では必須と README に書く）

## 動かし方の方針

- まず PC で作って試す。ネットのサーバーは使わない
- PC で本番と同じ形を動かせる道具を使い、あとからネットに置けるようにする。第一候補は Cloudflare Workers と wrangler。土台が動かなければ Python（FastAPI）に切り替える
- API キーはサーバー側に置く。`.env` はコミットしない
- 画面は素の HTML と JavaScript
- 審査員には、README の手順で試してもらう。余力があればネットに置いて URL も出す
- ネットに置くときは、本物の家族の写真を入れない。回数の上限、止めるスイッチ、自動の削除、注意の表示を付ける
