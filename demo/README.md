## ルール

- 動画ファイル本体（録画・音声・書き出し）は、リポジトリに入れない（`.gitignore` の対象）。置き場所は、ローカルと Google ドライブ
- 動画は、`storyboard.md` から作る生成物。動画を直接いじらず、`storyboard.md` を直して、書き出し直す
- **提出できる状態の動画を、常に1本保持する。** 新しい版は、別のファイル名で書き出し、通しで確認できてから差し替える
- 提出したら、下の「提出の記録」に書く

## 長さと提出の形式
