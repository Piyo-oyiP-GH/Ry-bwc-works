# log — 日々の記録（素材置き場）

1日1ファイル（`YYYY-MM-DD.md`）。セッションごとに下へ追記していく。
質は問わない。あとで README や提出文・デモ動画の台本にまとめ直すための素材。

- 追記はファイルの**末尾だけ**（他のセッションと同時に書いても、衝突を直しやすい）
- 書く前に `git pull`。書いたらすぐコミット

## ひな形

```markdown
# YYYY-MM-DD

## HH:MM ごろ [役割] <セッションの名前>（場所：claude.ai / Claude Code / Codex）

### やったこと
-

### 決めたこと
-

### 作ったもの
- [名前](URL) — 一言

### 残った疑問・次やること
-
```

## claude.ai で使う文（貼り付け用）

claude.ai のチャットは CLAUDE.md を自動では読まない。Codex は AGENTS.md を読む（中身は CLAUDE.md を指すだけ）。

**始めるとき**（最初のメッセージの先頭に貼る）

```
リポジトリ Piyo-oyiP-GH/Ry-bwc-works の CLAUDE.md を読み、そのルールで作業してください。このチャットの役割は「<考案／実装／その他>」です。
```

**終わるとき**

```
このチャットの記録を、CLAUDE.md のルールで log/<今日の日付>.md の末尾に追記する1ブロックとして書いてください（やったこと・決めたこと・作ったもの・残った疑問）。決定事項・作ったものは、decisions.md と artifacts.md に足す行も別に出してください。
```

リポジトリに書き込めないチャットでは、出てきた文をユーザーが Claude Code のセッションに貼って追記してもらう。
