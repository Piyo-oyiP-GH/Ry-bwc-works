## 11:40:47 問い
3D/質感・光：プラスチック額の曇り・拭きキズ、写真の紙質、背後の淡い光の柔らかな明滅、ほこり・光の粒・ビネットをコードで作る。CSS 3D＋SVG feTurbulence で作るか、Three.js か。どのスキル/参照か

### 答え
**使うスキル**
- **`hyperframes`** が主役です。見るのは `references/types/3d.md` と `runtimes.md` で、必要なら `path-tracing.md` も見ます。
- **`hyperframes-cli`** は `check`、`snapshot`、`render` の確認用に補助で使います。

**CSS 3D＋SVG か Three.js か**
- 質感の層は、CSS 3D と SVG の `feTurbulence` を主にするのが安全です。
  - 対象は額の曇り・拭きキズ、紙質、ほこり・光の粒、ビネットです。
  - 写真・額・テーブルの傾きと回転は、CSS 3D の transform で足ります。
  - 光の明滅は、GSAP の `onUpdate` で時間の関数として動かします。
- ただし `feTurbulence` を時間で動かすなら、`seed` や `baseFrequency` を時間から決めます。
- 乱数は `Math.random()` を使わず、seed 付きのハッシュにします。
- Three.js は、円卓ごと回って奥の光が前に出る場面（コマ2）で、本物の奥行きや柔らかい影がどうしても要るときだけ使います。
  - 使うなら、描画は `hf-seek` の `e.detail.time` から行い、重い準備は `buildReady` に登録します（`types/3d.md`、`runtimes.md`）。
  - `path-tracing.md` のパストレース（光を物理的に追う重い描画方式）は、このPCにハードウェアGPUがなければ重すぎるので、使わない方がいいです。
- 結論は、質感は CSS＋SVG、空間移動だけ必要なら CSS 3D にします。それでも足りないときだけ Three.js の raster モードに切り替えます。

**似たスキルとの比較**
- 既製のブロックを探すなら `hyperframes-registry` が近いです。ビネットや粒子の部品を使えるかは `discovery.md` で確認してください。ただし「額の曇り」のような固有の質感は手作りになります。
- ビネットやグレインの数値レシピは `media-use` の `media-treatment-recipes.md` にあります。ただしこれは素材に当てる加工用で、コードで質感を作る今回の用途とは別です。参考にする程度にしてください。

**使わない方がいいスキル**
- `remotion-*`（markup、3d.md、light-leaks.md など）は、HyperFrames と流儀が混ざるので避けます。
- `huashu-art-motion` は、参考の文書と `toon.js` を柔らかい質感の参考として読むだけにします。エンジンごとは持ち込みません。
- `remotion-to-hyperframes` は、移植ではないので不要です。
- `gsap` は、明滅やタイムラインのときだけ補助で使います。

`judge_log.md` に、この答えと従ったかどうかを残してください。
