# 動画スキル比較の結果（11/06 実施）

**結論：伏せた採点では、動画1（スキル多数＋判断係）が2モデルとも1位。ただし差は小さく、増やしたスキルが効いたとは言えない。** 動画1は追加した11個のスキルをどれも使っていない。

## 点数（30点満点。条件を伏せて採点、修正前の out_v1 を対象）

| | 動画1：多数＋判断係（C） | 動画2：厳選3つ（B） | 前回の動画の最初の6秒（A） |
|---|---|---|---|
| Sonnet | **20**（1位） | 19（3位） | 20（2位） |
| Opus | **22**（1位） | 19（2位） | 19（3位） |

- Sonnet の 20 対 20 は同点で、絵コンテに合っている方を上にしている
- 動画1の強み：3〜6秒の動きが滑らかで、光が前に出る流れが途切れない
- 動画1の弱み：写真がアイコンのようで、質感は3本の中で弱い（Sonnet 2点、Opus 3点）
- 見た目の質は前回の動画が一番（Sonnet 5点、Opus 4点）だが、円卓の回転がない

## 作成と修正

| | 動画1 | 動画2 |
|---|---|---|
| 作成の時間 | 6分17秒 | 4分55秒 |
| 作成の費用（判断係の分は除く） | 約 $1.68 | 約 $1.37 |
| 判断係への質問 | 4回（ほぼ従った） | なし |
| 修正の時間 | 1分34秒 | 1分7秒 |
| 光を暖かく | 直った（明部の R/B 比 1.35→1.51） | 直った（1.55→1.77） |
| 回転を半分の速さに | 直った（165°→82.5°、時間は同じ） | 直った（180°→90°、時間は同じ） |
| 頼んでいない所 | 崩れなし。ただし光は前まで来ず、卓の右で止まる | **最後に写真が画面の外へ出て消える**。光は中央に来るが前に出た感じは弱い |

- どちらも「半分の速さ」を、時間を延ばさず角度を半分にして実現した。6秒に収めるためだが、絵コンテの「光が前に出る」は2本とも弱くなった
- 動画2の作業者は「頼まれていない所は変えていない」と書いたが、写真が消えることには触れていない（`sheets/video2_v2_last.jpg`）
- 0〜3秒の v1 と v2 の差は小さく（平均 0.72／0.77）、色の変化の範囲

## 実際に使ったスキル

- どちらも実質 hyperframes スキルだけ。gsap と hyperframes-cli の SKILL.md は2本とも読んでいない
- 動画1だけが読んだのは hyperframes の中の `motion.md`・`look.md`・`review.md`。これらは動画2にも入っていた
- 動画1の差は、スキルの数より、判断係に場面ごとに聞いて、見直しの工程を踏んだことから来た可能性がある（この実験では切り分けられていない）
- 判断係は誤りも1つ出した（長さを15秒と確認するよう答えた。判断係には brief.md の 15秒 の記述しか渡っていなかったため）

## 確かめたこと

- 採点者2人が指摘した動画2の 3.5〜4秒の「飛び」は、全コマを測るとカットではなく速い連続の動きだった。その区間の動きは動画1の約2倍
- 動画2の修正後の写真の消失は、最後のコマを見て確認した

## 限界

- 各条件1本ずつなので、差が偶然の可能性がある。Sonnet では 1点差
- 採点者は MP4 を見られず、1秒・0.5秒ごとの一覧で判断した
- 修正後の v2 は伏せた採点をしていない。修正の判定は進行役が測定と目視で行った
- 作業時間はどちらも20分の枠の3割以下で、枠を使い切っていない
- 作業者のシェルは、安全判定を受けて許可コマンドを絞った状態で動かした（`log.md`）
